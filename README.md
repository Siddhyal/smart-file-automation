# Smart File Automation

A Python desktop application that automatically organizes messy folders by sorting files into folders based on their file types.

## 📸 Application Preview

![Smart File Automation](screenshot.png)

## 🚀 Features

- Automatically organizes files
- Detects file types
- Creates folders automatically
- Preview mode before making changes
- Simple graphical user interface
- Helps keep folders clean and organized
- Fast file processing

## 🖥️ How It Works

1. Select the folder you want to organize.
2. Preview the files that will be moved.
3. Start the automation.
4. The application creates appropriate folders.
5. Files are automatically moved into their corresponding folders.
